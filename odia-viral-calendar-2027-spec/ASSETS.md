## Image treatment
- Use AVIF/WebP for web photos where quality allows.
- Hero image should be high quality and not oversized; preload only if it is the primary LCP image.
- Lazy-load below-the-fold photos.
- Use consistent color and crop treatment without altering product details.
- Keep original, high-resolution assets outside the web export pipeline.
- Use descriptive filenames such as `calendar-2027-box-hero.webp`, `festival-raja-front.webp`, `story-buyer-01.webp`.
- Provide meaningful alt text for product/story images. Decorative motifs use empty alt.

## Font and Odia checks
- Supply licensed font files or use a properly hosted font provider.
- Test Odia conjuncts, punctuation, and line breaks on Android Chrome, iPhone Safari, Instagram in-app browser, and WhatsApp in-app browser.
- The main Odia display title should remain the original SVG artwork, not a retyped approximation.

The generated sample is a layout/art-direction reference only. It must not be used as evidence for product contents, customer stories, actual remaining stock, or final Odia typography. Replace all generated people/product representations with real approved assets before launch.
